# Donneil Rey Lauron — Media Buyer Portfolio

A responsive, single-page portfolio website prepared from the details in Donneil's media buyer resume.

## Preview locally

Open `index.html` in a web browser. The page uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.

## Publish with GitHub Pages

1. Create a new GitHub repository for the portfolio.
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published site URL in the Pages settings after deployment.

## Content note

The e-commerce case study is explicitly labeled as a demo. Its ROAS, purchase count, cost per purchase, CTR, budget, and other campaign details are sample figures from the resume, not verified client results. Update or remove them if you later add a real, permission-cleared case study.

Contact details and social links are included as supplied in the resume. Review them before publishing.
